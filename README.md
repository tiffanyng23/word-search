# Word Search
Recreated the classic word search game. You can easily customize the minimum word length, number of words, and size of the board within constants.py. By default, I have set it so players must search for 10 words of a minimum word length of 4.

When a correct word is found, the boxes containing the letters in the correct word turn green. When all the words in the word search are found, a win status message will appear.
